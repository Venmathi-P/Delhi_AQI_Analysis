# Delhi AQI Analysis

## 📌 Project Overview
This project presents a comprehensive analysis of Delhi's Air Quality Index (AQI) using Python. It explores pollutant trends, seasonal variations, and statistical insights to better understand the environmental challenges affecting Delhi's air quality.

## 🎯 Objectives
- Analyze major air pollutants in Delhi.
- Identify seasonal variations in AQI.
- Perform statistical analysis on pollution data.
- Visualize pollutant trends using charts.
- Suggest strategies for improving air quality.

## 📊 Dataset
The dataset contains air quality measurements including:

- PM2.5
- PM10
- CO
- NO2
- SO2
- O3
- NH3

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Jupyter Notebook

## 📈 Analysis Performed

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Pollutant Distribution
- Correlation Analysis
- Seasonal Analysis
- Statistical Analysis
- Data Visualization

- Output Screenshots

## 🚀 How to Run

1. Clone the repository.
2. Install the required libraries.
3. Open the notebook.
4. Run all cells.

## 📌 Conclusion

The analysis shows significant seasonal variations in air pollution levels. PM2.5 and PM10 are among the major contributors to poor air quality. These insights can help support environmental planning and public health initiatives.
